# Demo de Monitoreo Web con Prometheus y Grafana

Este repositorio contiene la infraestructura como código (IaC) y una API de prueba para demostrar la recolección y visualización de métricas en tiempo real.

## Requisitos
- Docker y Docker Compose instalados.

## Cómo levantar el entorno (Despliegue)
1. Clona este repositorio.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta el comando:
   ```bash
   docker-compose up -d --build
